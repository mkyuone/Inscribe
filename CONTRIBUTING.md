# Contributing

Thanks for your interest in Inscribe Editor! This project welcomes feedback, ideas, and improvements.

## Feature Requests & Issues

- Please open an issue for feature requests, bugs, or questions.
- Be as clear as you can and include steps to reproduce if it’s a bug.

## Contributions

- Contributions are welcome. Feel free to open a PR.
- If you’re unsure about the approach, open an issue first so we can discuss.
- I sometimes use ChatGPT Codex to help with this project — it’s been a pretty great tool. Feel free to use it too if it helps.

Thank you for helping make Inscribe better.
